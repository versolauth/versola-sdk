# Versola OAuth SDK 0.3.1

This patch improves Flutter package discovery and release publishing. There are no runtime or public API changes from 0.3.0.

## Flutter package

- Describe Versola as an OAuth 2.0 / OpenID Connect SDK and AppAuth alternative for Android and iOS.
- Explain migration requirements and link directly to the Flutter quick start and AppAuth migration guide.
- Add package topics, homepage, issue tracker and documentation metadata.
- Declare `meta`, which is imported by the generated Dart bridge and was already resolved transitively.

## Publishing

The pub.dev workflow now runs on a release tag from main. It analyzes and tests the package, prepares the iOS dependency for distribution, waits for `io.versola:oauth-android:0.3.1` on Maven Central and uploads through GitHub OIDC. Pub.dev must trust `versolauth/versola-sdk`, tag pattern `{{version}}`, environment `pub.dev`.

## Upgrading

Use `versola_oauth: ^0.3.1` on Flutter, `io.versola:oauth-android:0.3.1` on Android, or the Swift package at tag `0.3.1`, product `VersolaOAuth`. Platform requirements are unchanged.
